# TechCorp SaaS - Company Profile

## About
TechCorp is a growing B2B SaaS company that provides a cloud-based project management and team collaboration platform called **TechFlow**.

## Product
**TechFlow** - An all-in-one project management tool with:
- Task management with Kanban boards
- Team chat and messaging
- File sharing and document collaboration
- Time tracking and reporting
- API integrations (Slack, GitHub, Jira, etc.)
- Automated workflows and triggers
